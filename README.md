# Resultados Obtenidos

Durante el desarrollo de la actividad se logró comprender el funcionamiento de la librería Pandas y su importancia en el análisis de datos.

Los ejercicios realizados permitieron:

- Crear DataFrames utilizando diccionarios de Python.
- Organizar información en filas y columnas.
- Realizar operaciones matemáticas entre columnas.
- Leer y manipular archivos CSV.
- Generar datos sintéticos utilizando NumPy.
- Comprender cómo Pandas facilita el análisis y procesamiento de información.

Además, se fortalecieron habilidades en programación con Python y manipulación de datos estructurados.
